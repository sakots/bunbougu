# ローカルノート

- ノートは一意のページ名と本文を持つ。ページ名は前後の空白を除いて比較し、大文字と小文字を区別する。空の名前と、`[`・`]` や改行を含む名前は使用できない。
- ページを開き、本文を編集して「保存」を押す。新規ページは保存するまで一覧に表示されない。未保存の編集がある間はページ移動できない。「変更を戻す」で最後に保存した本文に戻せる。
- 保存済みページは編集欄の横（狭い画面では上）に、ファイルアイコン付きの一覧として表示する。名前順に並べ、同じ部分に続く数字は数値順に扱う（例: ノート2、ノート10）。行を選ぶとページを開き、開いているページの行を強調する。件数が多い場合は一覧内をスクロールできる。
- 本文中の `[[ページ名]]` は本文下の「ページリンク」に表示される。未作成のページを開いた場合は空の編集画面を表示する。空のリンクや、改行を含むリンクは無視する。
- 既定の保存先は OS のアプリデータディレクトリ。Windows・Linux などのデスクトップ版では「保存フォルダーを選択」から、ノートをまとめた `notes.json` の保存先を変更できる。選んだフォルダーに `notes.json` があれば読み込み、なければ空の一覧を開く。元のフォルダーのノートは移動・コピーしない。
- 選択した保存先は再起動後も使用する。未保存の編集がある間は切り替えられない。切り替え先の読み込みや書き込み確認に失敗した場合は元の保存先を維持し、エラーを表示する。
- この版では端末間同期は行わない。
