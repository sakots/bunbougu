# ローカルノート

- ノートは一意のページ名と本文を持つ。ページ名は前後の空白を除いて比較し、大文字と小文字を区別する。空の名前と、`[`・`]` や改行を含む名前は使用できない。
- ページを開き、本文を編集して「保存」を押す。新規ページは保存するまで一覧に表示されない。未保存の編集がある間はページ移動できない。「変更を戻す」で最後に保存した本文に戻せる。
- 本文中の `[[ページ名]]` は本文下の「ページリンク」に表示される。未作成のページを開いた場合は空の編集画面を表示する。空のリンクや、改行を含むリンクは無視する。
- 保存先は OS のアプリデータディレクトリで、再起動後も保存済みページを開ける。読み込み・保存に失敗した場合は画面にエラーを表示する。読み込みに失敗した場合は既存データを上書きしない。
- この版では端末間同期は行わない。
